# Background

`cognitive-architecture-design.md` is the owner's broader design for a functionally conscious assistant (merged from three independent designs, 2026-09-25). Tether's NPC mind is a small, game-sized test bed for some of its mechanisms (attention, workspace, belief, metacognition, attention schema, theory of mind, affect, learning), with the same rule: a mechanism counts only if ablating it changes behavior. It is context for the vision, not a spec: SPEC.md and DESIGN.md govern Tether. The three source designs it cites are not copied here.
