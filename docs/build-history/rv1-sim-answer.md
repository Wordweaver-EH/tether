2. **High — an agent can reach the hidden world through the shared JavaScript realm.** [headless.mjs:23](<C:/arcx/games/tether/src/headless.mjs:23>) calls agents in the simulation’s realm. 3. **High — a legal shallow slide can let a spear pass through an obstacle.** [sim.js:96](<C:/arcx/games/tether/src/sim.js:96>) treats displacement below `epsilon` as parallel, allowing repeated tiny penetration of an expanded obstacle boundary. The probe moved along A’s west side for 60 steps, threw from `x=-2.99999998`, and found the spear still `OUTBOUND` at `x=-0.9` after crossing A. **Fix:** prevent accumulated player penetration and treat a spear spawned on or inside static geometry as contact at `t=0`. Add a sustained shallow-slide-to-throw test.

4. **Med — the FOV includes points outside 60°.** [perception.js:15](<C:/arcx/games/tether/src/perception.js:15>) adds an absolute `1e-12` allowance. A point at `60° + 1e-13` radians returns visible; a point `1e-13` units directly behind the viewer also returns visible. [perception.test.mjs:8](<C:/arcx/games/tether/test/perception.test.mjs:8>) tests only a much wider outside angle. **Fix:** use a boundary comparison that does not widen the cone by a fixed world-unit amount, and test outside rays at several distances.

[log.test.mjs:124](<C:/arcx/games/tether/test/log.test.mjs:124>) tampers only with the hash. **Fix:** compare each sample and event against replayed output, or label hash verification narrowly and add tests that corrupt data fields and events.

6. **Low — the world hash depends on object key insertion order.** [sim.js:346](<C:/arcx/games/tether/src/sim.js:346>) stringifies nested objects. Rebuilding the same position as `{y: 0, x: -5.5}` changed the hash from `062c87adf2f53ea1` to `07bc6a9f10ec1c43`. This can reject semantically identical snapshots or reserialized logs. **Fix:** hash an explicit ordered sequence of scalar fields. The current `Map` use is lookup based; I found no iteration-order dependency.
