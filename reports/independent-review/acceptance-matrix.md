## Status vocabulary

- **Implemented / verified:** the stated implementation or measurement has direct source/test/data evidence, within the stated verification scope
- **Implemented / unsupported or negative:** code exists, but the proposed benefit/signature is unestablished, or the tested effect is adverse/null
- **Unimplemented / diagnostic-only:** a requested causal connection or test is absent; a trace/readout is not a substitute
- **Externally blocked:** acceptance requires the unavailable browser/human/external step; Node evidence cannot stand in for it
